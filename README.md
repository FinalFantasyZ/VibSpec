# VibSpec —— 振动信号分析器

**作者：yang** ｜ **项目主页：** https://github.com/FinalFantasyZ/VibSpec

一个本地桌面软件：导入振动采样文件，一键出**时域波形 / 频域幅值谱 / dB 功率谱 (PSD)**。
界面支持**中英文切换**，默认中文。

## 功能一览

- **自动识别文件格式**：兼容 CSV 与 MATLAB MAT，按文件内容判别结构后载入
- **时域 + 双频域视图**：时域波形 / 单边幅值谱 / Welch 功率谱密度（dB）
- **上下双窗口**：把不同通道分别画到两个窗口，解决多曲线重叠
- **信号预处理链**：高通滤波 / SVD 重构 / EMD 首个 IMF，可串接到包络谱分析
- **包络谱**：定位轴承故障特征频率
- **归一化**：跨来源增益相差上千倍时，仍可比较波形形状
- **导出**：当前图 / 谱线 CSV / 每个通道一张三联图
- **中英文界面**：菜单「语言 / Language」切换，选择会被记住

## 适用场景

旋转机械（电机、轴承、齿轮箱）的振动信号离线分析：观察波形、定位特征频率、
辅助判断故障类型。数据可由配套采集设备产生，也可来自任何能导出 CSV / MAT 的仪器。

## 二、支持的文件格式

软件按**文件内容**自动判别结构，无需手工选择。目前兼容两类格式：

| 格式 | 结构 | 解析要点 |
|---|---|---|
| **CSV** | 3 行文件头 + 数据行 | 首行给出采样率与通道数，另两行给出量程与显示基线；支持多通道 |
| **MAT（含元数据）** | 波形变量 + `capture_*` 元数据 | 采样率等采集参数随文件一并保存；波形变量名为 `signal` 或 `CH01` |
| **MAT（纯通道）** | 仅 `CHxx` 通道变量 | 文件内不含采样率字段，需人工指定 |

> **判别说明（2026-10-08 修正）**：较新的导出把波形变量由 `signal` 改名为 `CH01`，
> 与「纯通道 MAT」的通道名同形，因此**不能只靠波形变量名区分二者**。
> 现按元数据字段判别：含 `capture_*` / `history_payload_json` 者按「含元数据」解析，
> 其余含 `CHxx` 者按「纯通道」解析。此前版本会把前一类误判为后一类，
> 采样率被置为默认 20000 Hz，导致频率轴整体压缩（详见第五章第 3 条）。

### 各格式细节

#### 1. CSV
```
第 1 行:  20000,20000,3,0,5      ← 采样率, 采样率, 通道数, ...
第 2 行:  4.000,4.000,1.000      ← 各通道量程上限 (V)
第 3 行:  0,0,4                  ← 各通道显示基线
第 4 行起: 数据
```
- 第 4 行是导出器写的**全 0 哨兵行**，第 5 行是**满量程标记行**，软件会自动剔除。
- 标定方式：`电压(V) = raw × 通道量程 / raw满量程`。
  实测 `raw满量程 = 10.0593`，对应 **±10 V** 最大量程，
  因此 CH1/CH2 标定到 ±4 V、CH3 标定到 ±1 V，与第 2 行 header 完全吻合。
- 第 3 列（CH3）是**低分辨率辅助通道**（量化步长为 CH1 的 4 倍，仅 6 个电平），
  默认仍会载入但建议手动取消勾选。

#### 2. MAT（含元数据）
- 波形变量名随导出 schema 变化：**schema ≤2 为 `signal`**（1×N float64），
  **schema ≥3 为 `CH01`**（N×1 single）。后者与「纯通道 MAT」的 `CHxx` 同形，
  便于 MATLAB 侧统一写 `plot(CH01)`。本软件两种都识别，无需人工干预。
- 采样率取 `capture_effective_fs`（**有效采样率**，波形实际所在的时间网格），
  而非 `capture_fs`（配置值）。两者不一致时，文件信息面板会同时列出并给出提示。
- 附带工况元信息：`label_cn`（工况）、`fault_type_cn`、`severity_cn`、`rpm`、`created_at`。
- **注意**：此类数据常带明显直流偏置（实测约 −0.7 V），这是传感器/放大器的输出零点。
  软件的时域指标已把直流分离出去，RMS 只统计交流成分（详见下文）。

#### 3. MAT（纯通道）
- 变量名形如 `CH03`、`CH04`，各 **20001×1** float32，单位 V。
- **文件内不含采样率字段**，软件默认按 20000 Hz 处理，并在状态栏给出提示。
  请依据实际采集设置，在右侧「采样率 fs」框中手动更正——改完点「绘制/刷新」即可。

### 时域横坐标时间轴（2026-10-04 修正）

时间轴严格由**实际绘制的样本索引**换算：`t = 样本序号 / fs`。
此前存在四个会导致"时间轴偶发异常"的成因，已逐一修正并补充回归测试：

1. **处理链截断后 t0 越界**：处理链按 `Num` 截断信号（默认 16384 点，
   20 kHz 下只有 0.82 s）。若 `t0` 仍为 1.0 s，此前会切出一个**空数组**，
   横轴退化为 `0~1 s` 且不显示任何数据。
   → 现将起点限制在"仍可取得完整显示窗口"的范围内，超界时显示**最后一段**。
2. **横轴由最后一条曲线决定**：此前每条曲线绘制后即设置一次 `xlim`，
   导致窗口内**最后绘制的那条**曲线起决定作用；多文件采样率不同时，
   横轴会随绘制顺序变化。
   → 现改为在收尾阶段取本窗口**实际绘制数据的并集**。
3. **修改采样率会影响其他文件**：此前在"未选中文件"时，会将新采样率
   应用到**全部未锁定文件**。不含采样率字段的 MAT 默认未锁定，
   因此调整该数值框会一并修改这类文件的采样率、时间轴整体错位；
   同时因当时修改后**未触发重绘**，需等待下一次操作才显现，表现为"偶发异常"。
   → 现改为**仅修改选中的文件**（Ctrl/Shift 可多选）；未选中时给出明确提示，
   不进行静默批量修改。
4. **标题采样率显示错误**：此前标题始终显示 `files[0].fs`，与画面内容不符。
   → 现如实列出本窗口实际绘制的全部采样率，如 `fs=10000 / 20000 Hz`。

### 归一化开关（解决量级差导致看不见）

不同文件的增益可差**几十到上千倍**。实测峰峰值从 ~0.04 V 到 ~10.7 V ——
同一窗口里小信号会被压成一条平线。

右上「归一化」下拉框四种模式：

| 模式 | 含义 | 适用 |
|---|---|---|
| **不归一化（原始物理量）** | 纵轴就是真实的 V，不做任何处理 | 同来源数据对比，要看真实幅值 |
| **除以各自 RMS** | 去均值后除以各自有效值 | **默认推荐**，看波形形状/频谱结构 |
| **除以各自峰值** | 去均值后除以各自峰值 | 关心冲击峰值相对大小 |
| **Z-score** | 去均值后除以标准差 | 统计意义上的标准化 |

**两点重要说明：**

1. **归一化只影响绘图显示，不影响导出。**
   导出图片与导出 CSV 始终使用**原始物理量**，不会被归一化污染。
2. **全部归一化模式都会先去掉直流分量。**
   因为这类信号常带约 0.7 V 直流偏置，若只做除法，曲线会被整体抬到高位、
   波形压扁成一条粗线，反而更看不清。去掉均值让零点回到画面中央，
   才能用满纵向动态范围。想看真实直流请选「不归一化」。

- **时域起点 / 时域时长**：默认仅显示 0.05 s，避免整段波形重叠难以分辨。
  设为 0 则显示全程。
- **频率上限**：默认自动（= fs/2）；填具体值可放大看某个频段。
- **导出图片 / 导出数据 / 批量导出全部图片**：导出当前窗口当前图 / 谱线 CSV /
  每个通道一张三联图（时域+幅值谱+PSD）。

### 信号预处理链（包络分析）

右上「信号预处理链」分组用于**包络分析**。
**不勾选「启用处理链」时，软件直接对原始信号做谱分析**，不经过任何前置处理。

勾选后，信号按下面的链路处理：

```
原始信号 ──> [前置处理] ──> 包络（取模 + 三次样条插值） ──> 包络谱 FFT
              高通滤波
              或 SVD 重构
              或 EMD 首个 IMF
              或 不做处理
```

| 控件 | 含义 | 默认值 |
|---|---|---|
| **方式** | 前置处理方式：高通滤波 / SVD 重构 / EMD 首个 IMF / 直接取包络 | 高通滤波 |
| **FIR 截止** | 高通滤波的截止频率（-6 dB 点） | 500 Hz |
| **FIR 阶数** | 高通滤波器的阶数 | 180 |
| **Num** | 参与包络谱分析的样本数 | 16384 |
| **Lfr** | 包络谱显示的上限频点（约 (Lfr-1)×fs/Num Hz） | 800 |

- **傅里叶谱也用处理后的信号**：勾选（默认）时，幅值谱与 PSD 也基于处理后的信号；
  取消勾选则只在时域显示处理结果，频域仍用原始信号 —— 方便对照处理前后的频谱差异。
- **时域图在各方式下都会画出**：前置处理后的信号（实线）+ 上包络（虚线）± 下包络（点线）。
- **显示包络谱**按钮：把当前勾选信号的包络谱画到上窗口的「频域」页，
  横轴为 0~fs 的完整谱（**未归一的 |FFT|**）。

> 注意：包络谱不对单边谱做 ×2/Σw 归一化，纵轴为原始 |FFT| 幅值，
> 因此仅适合判断**峰位与相对高低**，并非物理幅值。
> 各处理方式的算法实现与数值验证见第四章。

## 四、算法与刻度定义（重要）

### 时域指标
- **均值 / 直流偏置**：原始信号的算术平均。带偏置的数据这里会显示约 −0.7 V。
- **峰值 / 峰峰值**：按**原始信号**（含直流）计算。
- **有效值 RMS / 方差 / 标准差 / 峭度 / 峰值因子等**：均在**去均值之后**计算。

  > 为什么要这样？实测某段数据里，直流偏置 −0.6956 V 远大于交流有效值 0.0025 V。
  > 若不去均值，RMS 会被直流项主导而虚高约 280 倍，峭度也会失真。
  > 已用「正弦 + 100 V 直流」的合成信号验证：分离后 RMS=0.7071、峭度=1.5000，
  > 与理论值完全一致。

### 幅值谱（单边 FFT）
- 公式：`A(f) = |X(f)| × 2 / Σw`，其中 `w` 为窗函数。
- DC 与 Nyquist 点不再乘 2。
- 刻度含义：**正弦波的峰值可以直接读数**。
  验证：2.5 V / 1000 Hz 正弦 → 谱峰读数 2.5000 V。

### dB 功率谱（Welch PSD）
- 方法：Welch 平均周期图，`scaling='density'`，单位 **V²/Hz**。
- 显示刻度：`dB/Hz = 10·log10(PSD / 1 V²/Hz)`（相对 1 V²/Hz）。
- 参数：`nperseg` 分段长度（默认 4096）、重叠率（默认 50%）、窗函数（默认汉宁）。
- 验证：2.5 V / 1000 Hz 正弦的 PSD 对频率积分 = **3.125** = `A²/2`，能量守恒成立。

> 用的是 **dB/Hz 功率谱密度**，不是简单对幅值取 20log10。
> 分段平均能压低随机噪声基线，适合看轴承故障特征频率。

### 预处理链算法（移植自廖志强的 MATLAB 实现）

#### 对照表：MATLAB 文件 ↔ Python 函数 ↔ 界面选项

| 项目提供的 MATLAB 文件 | Python 实现 | 界面「方式」选项 | 状态 |
|---|---|---|---|
| `filter_2sFIR.m` | `fir1_like` + `filter_2s_fir` | 高通FIR滤波 | 完整移植（含带通/带阻） |

#### `fir1_like` / `filter_2s_fir`（对应 `filter_2sFIR.m`）

- **实现必要性**：scipy 1.13 未提供 `scipy.signal.fir1`（仅有 `firls` /
  `firwin` / `firwin2`）。其中 `firwin` 的相位与归一化约定同 MATLAB 不一致，
  直接替代会使幅值刻度产生系统性偏差。
- **-6 dB 定义**：MATLAB `fir1` 的 cutoff 是 -6 dB 点。实测
  低通 n=180 fc=500Hz → **-6.00 dB @ 499.9 Hz**；高通 → **-6.00 dB @ 500.2 Hz**；
  带通 500–3000 Hz → 截止点 **-6.04 / -6.03 dB**。
- **支持四种滤波器类型**：`low` / `high` / `bandpass` / `stop`。
  理想原型 低通 `w·sinc(w·(m-α))`；带通 = 低通(w2) − 低通(w1)；
  带阻 = 低通(w1) + [delta − 低通(w2)]。
- **归一化问题 ①**：不能统一按 `h / sum(h)` 归一化。
  高通与带通的直流增益按构造为零（`sum(h) ≈ 0`），以此归一化会将系数
  放大约数千倍（实测中点抽头达 **-3808**），致使滤波器完全失效。
- **归一化问题 ②（2026-10-04 由测试发现）**：按参考频率归一化时必须除以
  `abs(H(fref))`，**不能**除以 `real(H(fref))`。
  滤波器是线性相位，`H` 带一个 `exp(-j·fref·n0)` 的相位因子，取实部等于
  额外乘了 `cos(相位)`。低通(fref=0)与高通(fref=π) 的相位恰好是 0/π，
  故此前未暴露该问题；带通的参考频率位于通带中部、相位任意 ——
  实测取实部会把**整个通带抬高 3.01 dB**。改成 `abs` 后带通通带回到
  **+0.00 dB**、截止点 -6.04/-6.03 dB。
- **高通/带阻强制偶数阶**：奇数阶对称 FIR 在 Nyquist 必为 0 增益，MATLAB 会 n+1。
  实测 `n=181` 高通 → 自动变 183 抽头。
- **滤波方式**：`filtfilt` 零相位前后向滤波，保留 MATLAB 的
  `size(sig,2) <= 3*n` 长度保护。实测 100 Hz 被压制到 0.00000，
  2000 Hz 通过增益 0.9745。

#### `envelope_liao`（对应 `envelopeLiao.m`）

- 逻辑：`x=abs(x)` → 一阶差分找局部极值 → 对极大/极小点做**三次样条**插值。
- MATLAB `spline` 与 scipy `CubicSpline(bc_type='not-a-knot')` 一致（默认）。
- **验证**：对解析已知的 AM 信号 `(1+0.5cos(2π·20t))·cos(2π·2000t)`，
  提取的上包络与解析解 `|1+0.5cos|` 的**最大误差为 1.17e-09**（中段），
  包络谱主峰落在 19.53 Hz（真值 20 Hz，差一个 FFT bin = 1.22 Hz）。

#### `svd_liao`（对应 `SVDLiao.m`）

- 逻辑：Hankel 嵌入 `X(ED,K)` → `S=X·Xᵀ` 特征分解 → 奇异值降序 →
  分组 `U[:,SVs]·Vᵀ[SVs,:]` → **三段反对角线平均**重构。
- 保留 `ED > Num/2 → ED = Num - ED` 的自动修正。
- **验证（最强的那个）**：取 `SVs = 1..ED`（全部奇异值）时，
  重构与原信号**逐点误差 = 8.88e-16**（机器精度）。这是对索引与
  反对角线权重的强校验 —— 任一 off-by-one 都会破坏这个恒等。
  取前 3 个奇异值时相关系数 0.9953。

#### `envelope_spectrum` / `envelope_spectrum_pipeline`

- `abs(fft(up))`，横轴 `sf = fs*(0:Num-1)/Num`，与 MATLAB 完全一致。
- **不做归一化**（理由见第三章）。
- **端到端物理验证**：合成一个"外圈故障"信号
  （BPFO=76.3 Hz 调制 3000 Hz 载波）+ 噪声，
  经 `高通FIR → 包络 → 包络谱` 后，谱峰落在 **76.90 Hz** ——
  与真值 76.3 Hz 相差一个 FFT bin 以内。说明链路在物理上是有效的。

#### 已知边界

- `SVDLiao` 的反对角线重构是**纯 Python 三重循环**。ED=28、Num=16384 时
  约 16000 次迭代，够快；但若把 ED 设得很大（几百以上）会明显变慢。
- `filter_2s_fir` 在信号长度 ≤ 3n 时抛错（与 MATLAB 一致），
  这是 filtfilt 的边界外推要求，不是 bug。

## 五、已知现象与判读提醒

1. **默认「不归一化」是刻意的：物理量必须真实。**
   实测跨来源增益差异极大：

   | 样例 | 交流有效值 | 峰值 |
   |---|---|---|
   | A | 0.5565 V | ~4 V |
   | B | 0.00248 V | ~0.71 V |
   | C | 0.0811 V | ~0.85 V |

   最大与最小相差 **225 倍（47.0 dB）**；PSD 能量比 47.1 dB，两者自洽。
   这来自采集链路的**增益/量程设置不同**，不是设备状态差异。
   软件默认不做归一化，以免破坏物理量的真实性；混画时状态栏会给出量级提示，
   **要看形状就打开「归一化」**（见第三章）。

2. **曲线重叠有两种成因，对应两种解法：**
   - 量级差太大 → 打开**归一化**
   - 就是想分开看 → 用**上下双窗口**分配

3. **含元数据的 MAT，其采样率是"实测有效值"，可能略低于配置值（2026-10-08 新增）。**
   此类文件以开机墙钟标定读取速率，同时记录配置值（`capture_fs`，如 31580 Hz）与
   实测有效值（`capture_effective_fs`，如 31039 Hz），二者相差约 1.7%。软件按**有效值**
   建立频率轴（它对应波形实际所在的时间网格），并在文件信息面板同时列出两者。
   采集端写入的 `capture_rate_warning` 会原样显示在该面板的「提示」区。
   采样率锁定规则：文件自带值与配置值**偏差 ≤1%** 时判定该值可信，采样率保持锁定
   （「采样率 fs」框对它不生效）；**偏差 >1%** 时判定该值存疑，**自动解除锁定**，
   可直接在「采样率 fs」框中按已知频率源重新标定后重绘。

4. **不含采样率字段的 MAT，其 fs 必须人工确认。** 默认 20000 Hz 只是占位。

5. **直流偏置不是故障特征。** 它来自传感器零点，看频谱前已去均值。

## 八、启动故障排查

**症状：** 命令行窗口一闪而过，报 `'cho' 不是内部或外部命令` / `'use' 不是内部或外部命令`

**原因：** `.bat` 文件的换行符或编码不正确。`cmd.exe` 逐字节解析批处理文件，
遇到 **LF（仅 `\n`）** 换行会将命令截断为片段；中文若以 UTF-8 存储且无 BOM，
在 936 代码页下会解码成乱码。

**本项目的处理：** `start.bat` 已固化为纯 ASCII 内容 + UTF-8 BOM + CRLF 换行。
如需自行编辑该文件，请务必保持上述三项约定，否则会重现该故障。
若文件已损坏，可使用 `run.py` 启动。

**验证编码是否正确：**

```bat
python -c "d=open(r'start.bat','rb').read(); print('BOM',d[:3]==b'\xef\xbb\xbf','CRLF',b'\r\n' in d, 'no bare LF', b'\n' not in d.replace(b'\r\n',b''))"
```
